What changed in 3.3.4

  • Material icons are gone. 944 call sites across 101 semantics now draw from the house vector family — 107 action glyphs and 195 module glyphs — the material-icons dependency is deleted from both build files, and a guard test fails the build if the package, a symbol or the dependency reappears.
  • One chat, one module, one icon. Every imported conversation gets its own encrypted directory, that directory rides the realtime wire as folder (schema, fixtures and contract doc updated), and the chat's glyph comes from a 16-member board keyed on the chat id. Twelve new tests pin id stability, container round-trip, board determinism and phone/web slot agreement.
  • The send confirmation shows the trust verdict. Each pre-signing check — address grammar, chain id, token contract, balance, fee — is rendered line by line with its pass mark, and "Confirm & send" stays disabled with the refusal reason until every one passes, instead of failing only inside the signing path.
  • WhatsApp export and import are wired end to end in the vault: seal a shared chat, read it as bubbles, and write it back out as the .txt or .zip shape WhatsApp itself produces.

Known honest gap: the brief named a "Shiva" chain. No such chain exists in any registry this wallet can resolve, so it is not in ChainRegistry; inventing a chain id would make every address rule, fee and broadcast against it wrong. BNB Smart Chain, Ethereum, Polygon, Bitcoin and Tron are live.
