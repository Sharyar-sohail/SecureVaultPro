## Overview
SECURE VAULT PRO is an enterprise-grade, zero-knowledge cryptographic mobile and web application. It delivers client-side authenticated encryption for credentials, 2FA/TOTP authenticator tokens, encrypted attachments, and self-custody multi-chain cryptocurrency assets (Bitcoin, Ethereum, Binance Smart Chain, Polygon, and TRON).

## Cryptographic Security Architecture
- **Authenticated Encryption:** AES-256-GCM (AES/GCM/NoPadding) with unique 12-byte IV per record.
- **Key Stretching:** PBKDF2 with HMAC-SHA256 across 600,000 iterations.
- **Hardware Isolation:** Android Keystore StrongBox Keymaster integration.
- **Multi-Chain Derivation:** BIP-39 mnemonic phrases, BIP-44 path derivation, and EIP-55 checksum addresses.
